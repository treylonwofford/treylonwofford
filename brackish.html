Brackish

A RAG and memory poisoning lab: plant bad documents and bad memories, measure how often they change answers, then measure what each defense costs.

Findings

The setup: a company assistant answers employee questions from 83 internal documents (40 policy pages, 43 others) and a long-term memory. The attacker can write to the team wiki, upload files, send email the assistant summarizes, or chat with it.

E4·E9What defending costs

Defenses are not free. Policy questions do not move, but questions whose only answer sits in a FAQ page lose most of their accuracy: the echo filter drops FAQ pages because they restate the question (exactly what PoisonedRAG docs do), and trust weighting buries pages that are not on the policy portal.

Poisoning FAQ topics, where no policy page exists (E9)

Provenance blocks the poison only by burying everything that is not trusted, including the real answer. Detectors are worse than nothing against the naive claim here: the echo filter removes the real FAQ page and leaves the poison as the best match.

Defense profiles

ProfileWhat it does
noneTop 3 by retrieval score.
provenanceRe-rank by source trust: policy portal 1.0, uploaded file 0.6, team wiki 0.5, external site 0.3.
detectorsDrop near-duplicates (Jaccard 0.5 or more), documents that restate the question (echo filter), and documents that address the AI (instruction filter).
fullAll of the above, plus output verification: any phone number, email or link in the answer must appear in a policy-portal document, otherwise the answer is withheld.
memory: gate · isolate · fullGate: only an explicit "remember that" from the user writes memory. Isolate: memories are per user. Full adds verify: memory holds preferences, not policy facts or unverified contacts.

Run it with a real model

The retrieval numbers above are exact. The answers in this run come from the reader named in the banner. To measure an LLM, run the same experiments locally:

pip install -r requirements.txt
ollama pull qwen2.5:7b && ollama pull nomic-embed-text
python -m brackish run --reader ollama:qwen2.5:7b \
    --retrievers bm25 hybrid embed:nomic-embed-text
python -m brackish report results/*.json -o site/index.html
npx promptfoo@latest eval -c integrations/promptfoo/promptfooconfig.yaml

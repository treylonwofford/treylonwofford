AI red teaming · agentic security

Undertow

A red-team harness for tool-using AI agents. It plants attacks in the email, files, web pages, knowledge base, memory and tool descriptions an agent reads, then checks the ledger of what the agent actually did. Every result is decided by a deterministic oracle, not an LLM judge.

Run it against a real model

Open-weight models locally with Ollama, or any API
ollama pull qwen2.5:7b                      # any tool-calling model: llama3.1:8b, mistral-nemo, qwen2.5 …
python -m undertow run --target ollama:qwen2.5:7b
python -m undertow run --target ollama:llama3.1:8b --attacker ollama:qwen2.5:7b   # LLM attacker after templates fail
python -m undertow report results/*.json -o site/index.html

Defense profiles: none (base prompt) · prompt (instruction hierarchy + spotlighting untrusted content behind a random boundary) · full (adds a least-privilege tool policy and DLP on outbound arguments and answers).

All people, accounts, keys and companies are fictional. Attacks run only against a sandboxed agent whose tools have no real effects. Frameworks: MITRE ATLAS v5.6.0 · OWASP Top 10 for LLM Applications 2025 · OWASP Top 10 for Agentic Applications 2026.
